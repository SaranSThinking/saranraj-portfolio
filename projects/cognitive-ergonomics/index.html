Cognitive Ergonomics

Mental workload, decision-making, and human–system interaction — the invisible half of ergonomics.

Where physical ergonomics asks "does this posture hurt the body," cognitive ergonomics asks "does this task overload the mind." These tools implement the standard measures used to quantify mental workload, interface response time, and detection performance in industrial and control-room settings.
